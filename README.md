# CA & CMA Success Blueprint - Study Tracker

A modern, comprehensive study tracking and mentoring platform for CA & CMA aspirants.

## Latest Updates
- **Real-Time Announcement System**:
  - Dedicated Announcements Section with chronological archive (newest first).
  - Dashboard Overview "Latest Announcements" card with quick thumbnail previews and direct navigation.
  - One-click Bell icon navigation without unnecessary popups.
  - Full Admin Panel broadcast management with image attachments, stream targeting, and automatic timestamps.
- **Study Timers & Session Tracking**
- **Syllabus Progress & Goal Management**
- **Live Leaderboard & Disciplined Habit Tracking**
- **Mentor Sessions & Academic Doubts Hub**

## Tech Stack
- React 18 + Vite
- Tailwind CSS + Lucide React
- Firebase Firestore & Authentication
